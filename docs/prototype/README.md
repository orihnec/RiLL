# 布局原型（静态 HTML）

打开方式（不需要 Tauri、不需要 `npm run dev`）：

```powershell
start docs\prototype\layout.html
```

或直接双击该文件。页面顶部有 **A / B / C / D** 四个切换按钮，点左侧图标/侧栏可以在日历、求职、招聘、待办、邮箱、知识库之间切换，检查"顶栏控件是否随视图变化"。

## 四个方案

| 方案 | 说明 | 状态 |
|---|---|---|
| **A · 现状** | 顶部分段控件 + 侧栏玻璃卡 + 右键菜单 = 三套入口；小月历与类别常驻；AI 固定占 360px；邮箱/知识库是模态浮层 | 改造前 |
| **B · 单入口 + Context Bar** | 导航只留侧边栏（工作台 / 工具 / 设置）；顶栏只放当前视图相关控件；小月历只在日历视图出现 | **已落到代码** |
| **C · 图标栏 + AI 抽屉** | 侧栏换成 56px 图标栏，宽度还给内容；AI 变右侧抽屉（浮层、默认收起），主区宽度不再跳动 | 提案 |
| **D · 双栏分屏** | 左列表（340px）+ 右详情，适合邮件/会话"选一条看一条"；代价是日历视野变窄 | 提案 |

## 看图时重点看这几件事

1. **回到日历要几步**：A 要点顶部"周/月"；B/C/D 侧栏第一项就是日历。
2. **主区宽度是否稳定**：A/B 打开 AI 会挤压主区；C/D 的 AI 是浮层，主区不变。
3. **顶栏是否只有"当前视图需要的控件"**：切到求职时不该看到日期导航。
4. **邮箱是不是"页面"**：A 里它是模态浮层（盖住整个界面），B/C/D 里它是与日历平级的页面。

## 选定之后

- 选 **B** → 已经实现，可继续做第 2 刀（邮箱/知识库页面化）。
- 选 **C** → 需要把 `Sidebar` 换成 `Rail` + AI 容器改为 overlay（`ChatDock` 从 flex 子项改成绝对定位抽屉）。
- 选 **D** → 需要给邮箱/会话类视图加"列表 + 详情"布局模式，日历视图仍保持整幅。
- 也可以 **C + D 组合**：图标栏 + 邮件双栏 + AI 抽屉。
