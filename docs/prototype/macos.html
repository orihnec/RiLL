Applications

把 Rill 拖到 Applications 即可安装（未签名版本需右键 → 打开一次）

为什么现在还不能直接给你 .dmg

Tauri 不能在 Windows 上交叉编译出 macOS 产物（要 Xcode 工具链 + Apple SDK）。 必须在 Mac 上 或 GitHub Actions 的 macos runner 上执行 npm run tauri build。代码已经为 macOS 准备好（原生 TLS 走 Security.framework、 图标含 .icns、bundle 段配置了 10.15 最低版本与 dmg 布局）。

拿到 Mac 后的三条命令

xcode-select --install → curl https://sh.rustup.rs -sSf | sh → npm i && npm run tauri build
产物：src-tauri/target/release/bundle/dmg/Rill_0.1.0_aarch64.dmg
未签名首次打开：右键 App → 打开；或 xattr -dr com.apple.quarantine /Applications/Rill.app
