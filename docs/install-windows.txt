Rill（日律）0.1.0 · Windows 安装说明
=====================================

一、怎么装
  1. 双击 Rill_0.1.0_x64-setup.exe
  2. Windows 可能弹「Windows 已保护你的电脑」（因为安装包没有购买代码签名证书）
     → 点「更多信息」→ 点「仍要运行」
  3. 按提示下一步即可，装完桌面/开始菜单会有 "Rill"

二、系统要求
  · Windows 10 / 11（64 位）
  · 如果系统缺少 WebView2 运行时，安装器会自动联网下载（需要能上网）
  · 首次启动需要联网一次（拉取界面资源不需要，但 AI 功能需要你自己的 API）

三、第一次打开要做什么
  1. 左下角齿轮 → 设置 → LLM 接入：填你自己的 API（如 DeepSeek / OpenAI 兼容接口）
     - Base URL、API Key、模型名；填完点「测试/识别模型」
  2. 想做邮箱功能：设置/邮箱页 → 添加账号 → 选服务商（QQ/163/Gmail…）
     - 密码处填「授权码」，不是邮箱登录密码
     - QQ 邮箱：设置 → 账户 → 开启 IMAP 服务 → 生成授权码
  3. 求职/校招：求职中心 → 校招库 → 「抓取并入库」

四、数据与隐私
  · 全部数据在你自己的电脑上：
      数据库  %APPDATA%\com.riliagent.app\riliagent.db
      API Key 与邮箱授权码存在 Windows 凭据管理器（不进数据库、不上传）
  · 没有服务器、没有账号体系；卸载程序也不会删你的数据库

五、关闭行为
  · 第一次关闭会问一次：最小化到托盘 / 退出程序，选完不再询问
  · 想改：设置 → 关闭窗口

六、卸载
  · 设置 → 应用 → 已安装的应用 → Rill → 卸载
  · 想彻底清数据：删除 %APPDATA%\com.riliagent.app 目录

七、常见问题
  · 双击没反应 / 被杀毒软件拦：加入白名单后重试（未签名的自制程序常被误报）
  · 提示缺少 WebView2：手动安装一遍
    https://developer.microsoft.com/microsoft-edge/webview2/
  · ARM 版 Windows：可以用，走 x64 兼容层运行
